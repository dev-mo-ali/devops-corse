One minute workflow

Pull → run → inspect → read logs → stop → remove. Each line is a separate command.

01  docker pull nginx:alpine
02  docker run -d --name web -p 127.0.0.1:8080:80 nginx:alpine
03  docker ps
04  docker logs -f web
05  docker stop web
06  docker rm web
Read before you run

Three distinctions that save time

Image → container

An image is a packaged template. docker run creates a new container; docker start restarts an existing stopped one.

EXPOSE ≠ publish

Dockerfile EXPOSE 80 documents a port. -p 8080:80 publishes host port 8080 to container port 80. Add 127.0.0.1: to bind locally.

Stop ≠ delete

stop keeps the container; rm removes it. Named volumes are managed separately. Check cleanup flags before deleting data.
