STEP 01

Prepare Ubuntu

Run these commands on your Ubuntu host, or in its SSH session.

Ubuntu · Bash 
sudo apt update && sudo apt upgrade -y

apt update refreshes package information. apt upgrade upgrades installed packages; -y accepts prompts. The && runs the upgrade only if the refresh succeeds.

A full system upgrade was your preparation step; it is not a Docker-specific prerequisite. It may restart services or require a reboot.

Already have another Docker installation?

Review conflicting distribution packages before following this fresh-install guide: docker.io, docker-compose, docker-compose-v2, docker-doc, docker-buildx, podman-docker, containerd, and runc. Check the official removal instructions first, especially on a host with existing workloads.

STEP 02

Add Docker’s signing key

APT uses this key to verify signed repository metadata.

Ubuntu · Bash 
# Add Docker's official GPG key:
sudo apt update
sudo apt install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
  • ca-certificates supports HTTPS certificate verification; curl downloads the key.
  • install -m 0755 -d creates the keyring directory with suitable permissions.
  • chmod a+r makes the public key readable by APT.

STEP 03

Tell APT where Docker lives

Paste this entire block into Bash, including the final EOF line.

Ubuntu · Bash 
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
FieldPurpose
URIsDocker’s Ubuntu package repository.
SuitesReads your Ubuntu codename, such as noble for 24.04.
ArchitecturesSelects packages for your host’s CPU architecture.
Signed-ByAssociates this repository with the key you downloaded.

Why refresh APT again? The repository is new. APT needs its package list before it can install Docker from it.

STEP 04

Install the Docker packages

This installs the latest versions available to your host from the configured repository.

Ubuntu · Bash 
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
PackageWhat you get
docker-ceThe Docker Engine daemon.
docker-ce-cliThe docker command-line client.
containerd.ioThe container runtime bundle used by the engine.
docker-buildx-pluginExtended image building through docker buildx.
docker-compose-pluginMulti-container applications through docker compose.

STEP 05

Check the Docker service

Ubuntu · Bash 
sudo systemctl status docker

Look for active (running). Press q to leave the status viewer if it opens in a pager.

If Docker is not running, start it and check again:

Ubuntu · Bash 
sudo systemctl start docker
sudo systemctl status docker

STEP 06

Run the hello-world container

Ubuntu · Bash 
sudo docker run hello-world

Expected output includes “Hello from Docker!”

  1. The CLI asks the Docker daemon to run the image.
  2. If the image is missing locally, Docker downloads it from Docker Hub.
  3. A container prints the confirmation message and exits.

An exited container is expected here. Its task is complete. Use sudo docker ps -a to see it; sudo docker ps shows only running containers.

Check the installed components

Ubuntu · Bash 
sudo docker version
docker compose version
docker buildx version
sudo docker ps -a

REVIEW

If something does not work

SymptomNext check
Package not foundCheck the repository file and the output of sudo apt update.
Cannot connect to the daemonCheck sudo systemctl status docker.
Permission denied on Docker socketUse sudo as shown in this lesson.
Image download failsCheck internet access, DNS, and any proxy settings.

For service startup errors:

Ubuntu · Bash 
sudo journalctl -u docker --no-pager -n 50
